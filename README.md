PixieBrix is a browser-based platform for customer care and enterprise operations teams that layers automation, AI assistance, integrations and real-time policy enforcement onto the web applications a team already uses, deployed as a lightweight browser extension and companion web app rather than an endpoint agent. Teams build "mods" from a library of prebuilt "bricks" — DOM readers, UI components, HTTP request bricks, AI/LLM bricks and data connectors — and administrators govern them centrally through activity policies, deployments, groups and audit trails. The public PixieBrix Developer API is a token-authenticated REST surface at https://app.pixiebrix.com/api/ covering team management, package/registry publishing, deployments, databases, activity policy and health checks, described by a published OpenAPI 3.0.2 specification.
